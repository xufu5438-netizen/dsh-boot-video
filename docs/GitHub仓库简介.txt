dsh-boot-video —— 给 DeepSeek Harness 加一段视频开机片头

打开 DSH 的时候，先全屏播放一段 mp4，播完淡出、露出真正的界面；不想看就点一下画面或按 Esc 跳过。

能做什么：
· 开机播放 + 随时跳过：不是"加载完就切走"，是一段真正的片头。
· 自带素材，也能用自己的：内置两段片头；导入自己的 mp4 会存进插件文件夹，可以起名、随时切换、马上重播预览。
· 自动转码：导入的视频如果是浏览器解不了的编码（典型是 4K 片源常见的 HEVC / H.265），插件会问一句要不要自动转换，点了就自己下载 ffmpeg（国内镜像，约 28MB，只下这一次）转成能播的 H.264，转完自动收进素材列表——不用你去学转码软件。
· 声音处理得体：桌面版直接带声播放；网页版被浏览器拦下未静音播放时自动降级静音，并亮出「打开声音」按钮。
· 不裁画面：始终按完整比例居中显示。
· 自检行：设置页底部写着"客户端是什么时候加载的""上次开机到底播成功没有"，改了没生效、视频打不开，看一眼就知道。
· 零运行时依赖：宿主半边只用 node: 内建模块，浏览器半边只有一条 <video>。

怎么装：
    dsh plugin --profile web add github:xufu5438-netizen/dsh-boot-video

桌面版走「设置 → 插件 → 添加插件」，把上面那行 github: 地址贴进去；装完完全退出 DSH 再重开，然后 Ctrl+Shift+R 硬刷新一次页面。

素材与许可：
· 代码 MIT。
· 随包自带的 HDD 开机动画已获作者授权，可随包分发。
· 插件不随包提供任何未授权素材；你自己导入的视频只存在你本机。
