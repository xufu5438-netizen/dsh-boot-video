DSH 视频开机片头插件 —— 功能介绍（发给朋友的版本）

【这是啥】
给 DeepSeek Harness（DSH）加一段视频开机片头：打开 DSH 的时候全屏播一段 mp4，播完淡出进界面。
不想看就点一下画面或按 Esc 跳过。

【功能】
1. 开机播放：启动 DSH 时全屏播放，播完自动淡出，不会一直挡着。
2. 随时跳过：点画面、按 Esc 都行。
3. 声音：桌面版直接带声音播；网页版如果被浏览器拦下（网页版的常态），会自动改成静音播，并在左下角亮出一个「打开声音」按钮，点它就有声。
4. 片头素材随便选：
   - 自带两段（HDD 开机动画 / 欢迎来到月读世界）
   - 也能导入自己的 mp4，起个名字，选中就用它
   - 换素材马上重播一遍给你看效果，不用重启
5. 自动转码（这个最省事）：导入的视频如果编码浏览器解不了（比如常见的 4K HEVC / H.265 片源），
   插件会问一句「要不要自动转换」，点一下它自己把 ffmpeg 下载下来（约 28MB，国内镜像，只下这一次）
   转成能播的格式，转完自动收进素材列表，你不用去学转码软件。
6. 有自检行：设置页底部会写「客户端是什么时候加载的」「上次开机是不是正常播完了」，
   改了没生效、视频打不开，看一眼就知道。

【怎么装】（网页版为例）
在终端里执行：
    dsh plugin --profile web add github:xufu5438-netizen/dsh-boot-video

桌面版：在应用里走「设置 → 插件 → 添加插件」，把上面那行 github: 开头的地址贴进去。
装完一定要「完全退出 DSH 再重新打开」一次，然后按 Ctrl+Shift+R 硬刷新一下页面。

【怎么用】
装好以后打开「设置 → 开机动画」（在设置侧边栏里单独一页）：
- 「启动时播放」选「我的视频」= 开发机动画；选「不播放」= 用 DSH 自带的界面
- 「片头素材」点哪段就换成哪段，右边「▶ 播放一遍」可以先看效果
- 「导入视频」挑一段你自己的 mp4（上限 512MB，只收 mp4）
- 导入完会自动弹个小窗口让你给它起名，也可以先用原文件名

【注意事项】
- 视频建议 1080p 或 720p、10 秒左右、几十 MB 就行：片头太长会拖慢启动观感（4K60 的也能放，就是文件大）。
- 导入的素材存在插件自己的文件夹里（assets/user/），删插件里那一份不会动你的原文件。
- 卸载：`dsh plugin --profile web remove dsh-boot-video`，卸载后就恢复成 DSH 自己的启动画面。

【其他】
- 插件里只带 HDD 那段片头是作者拿到授权的素材；「月读世界」那段只在自己机器上用，不随包分发。
